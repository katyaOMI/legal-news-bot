# Инструменты для проверки и развития бота

Проверено 11 ноября 2026 года. Владелец выбрал ручное сравнение Kimi и DeepSeek без новых оплат. Для первого учебного этапа новые сервисы не требуются. Возможности ниже взяты из документации авторов; качество на источниках бота и доступность из России/с сервера не проверены.

| Инструмент | Что делает | Где может помочь | Решение для первого этапа |
|---|---|---|---|
| [Grill with UI](https://github.com/jasonku09/grill-with-ui) | Локальная страница с вопросами, вариантами и итоговым документом; Node 20+, без дополнительных зависимостей по README | Уточнять сложные будущие функции перед спекой | Необязателен: вопросы можно обсудить в чате. Это средство проектирования, а не интерфейс для подписчиков |
| [Claude Codex Bridge](https://github.com/vasilievyakov/claude-codex-bridge/blob/main/README.ru.md) | Claude Code вызывает Codex для рецензии или отдельной задачи и проверяет результат | Автоматизировать второе мнение при разработке | Не устанавливать сейчас: выбран ручной путь через Kimi/DeepSeek; автор поддерживает macOS/Linux, Windows не поддерживается, WSL 2 не проверен; нужны доступы к Claude Code и Codex |
| [Exa Search](https://exa.ai/docs/reference/search) | Поиск страниц с возможностью получения текста; фильтры доменов и дат | Находить новые первоисточники и кандидатов для collector | Отдельный будущий эксперимент. Поиск не заменяет тематический отбор, проверку дат и первоисточников |
| [Tabstack](https://docs.tabstack.ai/) | Получение текста страницы/JSON, исследование и автоматизация браузера | Попытаться прочитать трудные публичные страницы, где обычная загрузка не справляется | Отдельный будущий эксперимент на проблемных URL. Успех на Госдуме/РКН не подтверждён; извлечённый текст всё равно проходит отбор |

## Стоимость и данные

[Exa](https://exa.ai/pricing) публикует Search от $4 за 1000 запросов и Contents $1 за 1000 страниц за тип содержимого; бесплатный стартовый кредит не гарантирует постоянной бесплатности. Это разные операции, общую стоимость нужно считать по выбранному запросу. Тарифы проверять перед подключением. Нулевое хранение запросов нельзя предполагать для любого плана: на странице цен оно вынесено в Enterprise.

[Tabstack](https://tabstack.ai/pricing) предоставляет новым аккаунтам 10 000 кредитов без карты; Starter указан как $10 в месяц. Markdown-извлечение стоит 10 кредитов, JSON-извлечение 50; исследование и автоматизация могут включать несколько действий. Это не разрешение покупать подписку.

По [Trust Tabstack](https://tabstack.ai/trust), подробная история запросов включена для новых организаций и хранится 90 дней, её сбор можно отключить. Обещание не обучать модели на запросах не означает отсутствия хранения или внешней обработки. Возможности с моделями передают содержимое подрядчикам; Pilo — отдельный открытый движок автоматизации, не самостоятельная локальная копия всего API Tabstack.

Для будущих внешних вызовов — только отобранный публичный текст без данных подписчиков и ответов на опросы. Заявления поставщика о защите данных сами по себе не доказывают применимость сервиса к конкретным юридическим требованиям пользователя.

## Как проверить пользу позже

Exa: на заранее выбранных запросах оценить число новых релевантных первоисточников, доступность текста, дубли, происхождение даты и стоимость. Результат поиска — кандидат, не готовая Telegram-карточка.

Tabstack: сравнить обычный сбор и извлечение на одинаковых публичных URL; проверить, получена ли статья целиком, не подменён ли текст меню/страницей ошибки, откуда взята дата. Ошибку доступа отражать прямо. Не обещать обход ограничений сайтов.

Не добавлять одновременно поиск, новое извлечение и модельный отбор: иначе невозможно понять, что именно улучшило или ухудшило результат. Ближайшее согласованное направление — отдельное ручное сравнение отбора; подробности в [черновике](SPEC.md).
